# 잼스 · Codex · Claude 작업 방식

상태: 연결 준비. 실제 Claude 실행과 결과 회수는 아직 검증하지 않았다.

## 역할
- 잼스: 원하는 수업 기능과 화면 피드백 전달.
- Codex: 실제 소스 확인, 작업 범위와 완료 조건 작성, GitHub 작업 등록, 변경 및 실행 결과 검수.
- Claude Code: 지정 작업 구현, 필요한 테스트 실행, 별도 브랜치와 PR 제출, 오류와 미완료 항목 보고.
- Codex가 작업 중일 때만 결과를 조회한다. 별도 자동화 없이는 대화 밖 상시 감시를 약속하지 않는다.

## 작업 규칙
1. 한 작업에 한 가지 목적을 담고 전체 대화 대신 관련 파일과 완료 조건을 전달한다.
2. 같은 파일을 두 AI가 동시에 수정하지 않는다. 진행 중 작업과 최신 main을 확인한다.
3. Claude는 main에 직접 push하거나 PR을 병합하거나 배포하지 않는다. 작업 브랜치와 PR로 제출한다.
4. 실패·사용량 제한은 원인과 필요한 조치만 보고하고 자동 반복 호출하지 않는다.
5. 키, 토큰, 학생 개인정보, 실행 데이터를 커밋하거나 로그에 출력하지 않는다.
6. 보고에는 변경 파일, 커밋, 실행한 검사와 실제 결과, 남은 한계, PR 주소를 포함한다.
7. Codex 검수 뒤 요청 범위 안에서 병합·배포하고 실제 주소를 확인한다.

## 일회 설정
공식 안내: https://github.com/anthropics/claude-code-action/blob/main/docs/setup.md
- Claude GitHub App에 이 저장소 접근 권한을 부여한다.
- Claude Code 인증을 설정한다. Pro/Max 사용자는 공식 claude setup-token으로 생성한 토큰을 이 저장소 Actions secret CLAUDE_CODE_OAUTH_TOKEN에 직접 저장한다. 채팅·소스·작업 보고에 값을 넣지 않는다.
- .github/workflows/claude-coding.yml을 main에 반영한다.
- 일반 GitHub gh 로그인과 Claude 모델 실행 인증은 별개다.
- GitHub Actions 실행 시간 및 Claude 이용 한도가 적용된다. Mac이 꺼져 있어도 GitHub 실행 환경에서 동작한다.

## 동작 검증
저장소 소유자 명의로 @claude를 포함한 작은 작업 이슈를 생성한다.
GitHub App 명의로 생성된 이슈가 작성자 제한에 걸리면 제한을 임의로 풀지 말고 작성자와 실행 로그를 확인한다.
첫 작업은 게임 동작을 바꾸지 않는 문서 보완으로 한다.
Actions 실행 → Claude 응답 → 별도 브랜치/PR → Codex 검수까지 확인한 후에만 연결 완료라고 보고한다.

## 첫 실제 게임 작업
십자말풀이 초기 소스를 검토하고 실행 오류가 있으면 근거와 함께 수정한다.
범위: index.html, app.js, data.js. 학생 데이터·다른 저장소·사이트 설정은 변경하지 않는다.
확인: 파일 로딩, 퍼즐 생성, 한글 입력, 정답 판정, 재시작, 모바일 터치.
브라우저 검사를 실행하지 못한 경우 미검증으로 명시한다.
