# 교사용 링크 안내

특정 단계·주제·번호의 낱말풀이로 바로 들어가는 주소를 만드는 방법입니다.
`README.md`와 `app.js`(`route()` 함수, `LEVELS`, `ERAS`, `STAGES`)에서 확인한 내용만 적었습니다.

## 주소 형식

이 게임은 `?level=...&topic=...` 같은 쿼리 매개변수를 사용하지 않습니다. 주소 끝의 해시(`#`) 뒤에 값을 넣습니다.

```
index.html#play/단계코드/주제코드/번호
```

- 단계코드: 아래 단계 표의 코드
- 주제코드: 아래 주제 표의 코드 (`all` 포함)
- 번호: 1~20 (단계·주제마다 낱말풀이 20개)

세 값이 모두 있어야 합니다. 형식은 `#play/` 다음에 영문·숫자·밑줄(`_`)로 된 두 값과 숫자 하나가 `/`로 구분된 형태여야 합니다.

## 단계 코드 (level)

| 단계 | 코드 |
|---|---|
| 입문 | `intro` |
| 초급 | `basic` |
| 중급 | `mid` |
| 상급 | `adv` |
| 고급 | `high` |
| 마스터 | `master` |

## 주제 코드 (topic)

| 주제 | 코드 |
|---|---|
| 전체 시대 | `all` |
| 구석기 | `gu` |
| 신석기 | `sin` |
| 청동기 | `cheong` |
| 고조선 | `gojo` |
| 삼국 시대 | `samguk` |
| 고려 | `goryeo` |
| 조선 | `joseon` |
| 일제 강점기 | `ilje` |
| 근현대 | `modern` |

코드는 소문자 그대로 입력합니다. 대소문자를 바꾸면 일치하지 않습니다(코드의 `===` 비교 기준).

## 예시 주소

실제 게시 주소 뒤에 해시를 붙입니다. (`https://example.com/`은 자리 표시이므로 실제 주소로 바꾸세요.)

- 입문 · 고려 · 3번: `https://example.com/index.html#play/intro/goryeo/3` (README 예시와 같은 형식)
- 중급 · 전체 시대 · 1번: `https://example.com/index.html#play/mid/all/1`
- 마스터 · 근현대 · 20번: `https://example.com/index.html#play/master/modern/20`

## 잘못된 값의 처리

아래 경우에는 오류 메시지 없이 낱말풀이를 열지 않고 처음(홈) 화면을 보여 줍니다.

- 단계코드가 표에 없는 경우 (예: `#play/easy/goryeo/3`)
- 주제코드가 `all`이나 표의 코드가 아닌 경우 (예: `#play/intro/korea/3`)
- 번호가 1~20 범위 밖인 경우 (예: `0`, `21`)
- 번호가 숫자가 아니거나 비어 있는 경우, `/` 개수가 맞지 않는 경우 등 형식이 맞지 않는 경우

## 참고

- 유효한 주소로 들어가면 그 단계와 주제가 이 브라우저의 마지막 선택으로 저장됩니다.
- 풀이 기록은 브라우저에 저장됩니다(README 기준).

## 검증 범위

- 소스(`app.js`, `README.md`)를 읽어 대조했습니다.
- 브라우저에서 실제로 주소를 열어 보는 확인은 하지 않았습니다. (미검증)
