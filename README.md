# 잼스 역사 낱말풀이

잼스.com(역사랑 놀자)의 한국사 십자말풀이 게임입니다.

- 단계: 입문 · 초급 · 중급 · 상급 · 고급 · 마스터 (단계마다 낱말풀이 20개)
- 주제: 전체 · 구석기 · 신석기 · 청동기 · 고조선 · 삼국 시대 · 고려 · 조선 · 일제 강점기 · 근현대
- 찬스 아이템: 초성 힌트 · 글자 열기 · 보기 찬스 · 검색 찬스 · 정답 공개
- 문제지·정답지 인쇄, 판마다 별·배지·색종이 축하 효과(소리는 선택)
- [잼스.com 낱말풀이](https://xn--9t4b56g.com/crossword/index.html)에서는 역사 탐험과 같은 학생 계정으로 로그인해 완성 기록과 풀던 판을 서버에 저장하고 다른 기기에서도 이어 풀 수 있습니다.
- 로그인한 학생 아이디 아래에 내 순위·레벨·총 경험치를 표시합니다. 탐험 경험치와 낱말풀이 판별 최고 점수 합계를 더한 통합 기록이며 1,000 XP마다 레벨이 오릅니다. 순위는 실제 학생끼리 계산하고 교사 체험 계정은 제외합니다.
- 이 GitHub Pages 복사본은 서버가 없는 정적 페이지이므로 기기 저장만 지원하며, 계정 저장을 이용할 잼스.com 주소를 안내합니다.
- 연결이 끊기면 계정별 기기 저장에 대기했다가 다시 전송합니다. 브라우저 저장이 제한된 환경은 현재 창에 임시 보관되며 서버 저장 확인 전 창을 닫지 않도록 안내합니다.
- 확인: `node --test test/resume.test.mjs`

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 디자인 |
| `account.js`, `account.css` | 학생 계정 저장 및 연결 상태·완료 효과 디자인 |
| `app.js` | 낱말풀이 생성, 풀이, 아이템, 저장, 인쇄 |
| `data.js` | 역사 낱말 1,002개 (`정답|난이도|문제`) |

서버가 필요 없는 정적 페이지입니다. data.js, app.js, account.js, account.css, index.html을 같은 폴더에 올리면 동작합니다. 계정 저장 API는 잼스.com의 공용 서버에서 제공합니다.

특정 낱말풀이로 바로 가는 주소: `index.html#play/intro/goryeo/3` (단계/주제/번호)
