# 잼스 역사 낱말풀이

잼스.com(역사랑 놀자)의 한국사 십자말풀이 게임입니다.

- 단계: 입문 · 초급 · 중급 · 상급 · 고급 · 마스터 (단계마다 낱말풀이 20개)
- 주제: 전체 · 구석기 · 신석기 · 청동기 · 고조선 · 삼국 시대 · 고려 · 조선 · 일제 강점기 · 근현대
- 찬스 아이템: 초성 힌트 · 글자 열기 · 보기 찬스 · 검색 찬스 · 정답 공개
- 문제지·정답지 인쇄, 기록은 브라우저에 저장
- 풀던 판은 답·찬스·시간이 이 기기 브라우저(localStorage)에 자동 저장되어, 다시 열면 ‘이어서 풀기’로 계속해요. 서버·계정 동기화는 없어요. ‘다시 풀기’를 누르면 저장한 풀이가 지워져요. 낱말 데이터가 바뀌어 판 모양이 달라지면 저장한 풀이는 버리고 새로 시작해요.
- 확인: `node --test test/resume.test.mjs`

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 디자인 |
| `app.js` | 낱말풀이 생성, 풀이, 아이템, 저장, 인쇄 |
| `data.js` | 역사 낱말 1,002개 (`정답|난이도|문제`) |

서버가 필요 없는 정적 페이지입니다. 세 파일을 같은 폴더에 올리면 바로 동작합니다.

특정 낱말풀이로 바로 가는 주소: `index.html#play/intro/goryeo/3` (단계/주제/번호)
